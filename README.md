# Лерусь, это тебе ✦

Личное приглашение на свидание для Леры. Статический сайт для GitHub Pages: без сборки, сервера, npm и внешних зависимостей.

Репозиторий: https://github.com/msmsat/dateme
Адрес сайта после публикации: https://msmsat.github.io/dateme/

## Открыть на компьютере

Дважды нажми на `index.html`. Вся папка должна оставаться рядом с ним: оформление, музыка, картинка и шрифты работают локально.

Для проверки через локальный адрес, если установлен Python:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открой `http://127.0.0.1:4173`.

## Разместить бесплатно на GitHub Pages

1. Войди на GitHub и создай **публичный** репозиторий `dateme`.
2. Через **Add file → Upload files** загрузи `index.html`, `styles.css`, `app.js`, `config.js` и папку `assets` в корень репозитория. Не загружай внешнюю папку `dateme` целиком: `index.html` должен находиться сразу в корне. Файл `.nojekyll` полезен при загрузке через Git; для этой структуры он не обязателен.
3. Открой **Settings → Pages**. В **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, нажми **Save**.
4. Дождись успешной публикации. GitHub покажет адрес вида `https://ТВОЙ-ЛОГИН.github.io/dateme/`.
5. Открой ссылку на телефоне и затем отправь Лере в Telegram.

Покупать домен не нужно. Для повторной публикации достаточно отправить изменения в ветку `main`: GitHub Pages обновляет сайт автоматически.

## Изменить место и время

Открой `config.js` и измени `date`, `place` и `dressCode`. На странице дата скрыта. «В понедельник в 19:30» находится только в `yesReply`: Лера увидит дату, когда вставит скопированный ответ в ваш чат. Сайт не отслеживает вставку или отправку сообщения. Место: Sumi Garden, Hybernská 17. Здесь же меняются тексты ответов. Обращения и письмо находятся в `index.html`.

## Что внутри

- Авторская лунная сцена с мягким розовым светом и сердечком, локально сохранённая в `assets/moon-lake-rose.webp`. Исходная золотистая версия сохранена в `assets/moon-lake.webp`.
- Личное письмо Лере и билет на свидание.
- Маленький секрет по нажатию на подпись у луны.
- Ответ «да» и возможность написать личное сообщение. Ответ копируется; ничего не отправляется автоматически. Лера сама вставляет его в ваш чат.
- Тихая мелодия через Web Audio API, только после нажатия. При сворачивании страницы останавливается.
- Адаптация для телефона, клавиатурная навигация, диалог с Escape, учёт `prefers-reduced-motion`.
- Без аналитики, cookies, форм сбора данных и сетевых запросов к третьим сторонам.

## Доступ к приглашению

Обращение личное, но ссылка GitHub Pages публичная: её сможет открыть любой получатель ссылки, а содержимое публичного репозитория видно на GitHub. Метатег `noindex` просит поисковики не индексировать страницу, но не является паролем или защитой доступа.
